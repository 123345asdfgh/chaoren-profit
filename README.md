- 数据库升级：`pnpm --filter @profit/api db:migrate`。新增业务流程验证：`pnpm --filter @profit/api measurements:smoke`（使用真实开发数据库验证，测试数据全部事务回滚）。
- 此次变更前备份位于 `work/backups/2026-11-05-editable-measurements/`；用户指定的页面基点仍保存在 `恢复基点.md` 指向的快照中。

## 用户默认配置（2026-11-05）

- 首次使用会从代码中的初始值复制一份用户配置（保留现有参数，代运营为 16%），之后直接读取和修改自己的配置。用户配置保存在 `profit.calculation_defaults`，一人一份、按身份隔离；系统初始配置表 `profit.global_settings` 已删除，不再有共享默认参数表。
- 只有点击「设为我的默认配置」才更新个人默认参数；结算汇率为例外，用户手动修改有效汇率即保存个人默认值。搜索商品、载入历史和接受对比方案不会修改个人默认配置。
- 商品搜索回填、历史载入和接受对比方案的参数仅属于本单，不自动变成用户默认值。对比每次打开采用用户默认配置；接受后按当次临时参数保存历史及商品快照。重开一单恢复用户默认值。
- `GET /api/profit/settings` 首次访问创建该用户的配置，返回本人配置和内部物流规则；`PUT /api/profit/settings` 只更新当前用户业务参数。初始值只在创建用户配置时复制一次；重复读取不会重置用户配置。普通测算保存不携带默认配置修改；个人默认配置通过独立设置接口更新。
- `apps/api/src/user-settings.ts` 提供 `resolveUserId(request)` 身份适配入口。迁入主项目时，向 `registerUserSettingsRoutes` 传入主项目服务端已认证的用户 ID，并设置 `standalone:false`；可将初始化配置挂到主项目用户创建流程，同一用户在不同设备使用同一份配置。身份不从前端提交的用户 ID 或请求头取得。历史、商品的共享规则保持独立。
- 当前独立版通过登录会话识别账号，采用服务端用户 ID 分区；旧匿名配置继续保留。
- 验证：`pnpm --filter @profit/api settings:smoke` 覆盖不同身份隔离、刷新读取、对比保存、历史共享、商品修改、恢复上一版及失败回滚；测试结束精确清理测试记录和默认配置。

## 页面与功能

- `/calculator`：直接进入原有测算界面，保留品牌区、中美实时钟、利润卡片、即时对比；不显示地球进入页。产品信息独立填写商品属性，中国组合价自动生成可修改的美区商品售价；“商品物流信息”位于产品信息下方，只展示商品自动回填的长宽高、实重，尺寸类型和店铺现场选择，按商品属性与渠道自动估算运费，直接填入实际物流成本，不单独展示预计成本。裸货先换算包装尺寸与重量。更换商品、尺寸类型、店铺或修改物流配置后，估算值自动填入实际物流成本；用户可以手动覆盖，修改成本不会反改物流输入，利润始终按实际物流成本输入框计算。载入历史记录只恢复原值，不用估算覆盖已保存成本。对比中的长宽高、实重也以只读信息展示，仍可选择尺寸类型、店铺并手动覆盖实际物流成本。人民币输入框位于北京时间卡片右下角，美元输入框位于美国时间卡片右下角，按统一配置汇率双向换算；半透明输入框随各自卡片的白天、晚霞和夜景背景调整配色，美国时间地区在统一配置中选择太平洋、山地、中部或东部。对比临时设置每次打开都从已保存的统一配置开始，接受新方案会按当次临时参数计算并保存为新版本。载入旧记录后可在页面下方修改本记录配置；此时右上角出现“重开一单”，用于清空已载入记录并新建一条独立记录。右上角还可打开统一配置弹窗或进入历史记录。计算页没有存档搜索栏。确认保存成功后弹窗提示当前版本。
- `/history`：默认显示所有人保存的测算记录，筛选后只显示符合条件的记录。可按商品名称、商品编码、规格编码、商品属性多选、操作人和日期搜索，每页可选 10、20、50 条。导出 Excel（.xlsx）使用当前筛选条件，导出全部匹配记录，不受当前页数限制；历史测算工作表每条记录横向占一行，使用分类标题和字段名称两层表头，按产品信息、物流信息、成交信息、基础参数、扣点与税费、物流计费、利润结果及记录信息分组；物流配置工作表逐条记录分块，按商品规则、各渠道运价和店铺规则列出完整配置。单元格居中、带框线，使用奶油橙分区及交替行，利润结果单独以绿色区分，冻结两层表头与记录序号、商品名称两列。计算页不再提供本单导出。查看详情弹窗可查看物流输入、预计运费、实际成本及该版本的完整配置，再选择载入并修改；也可恢复上一版或删除记录。页面不显示统计区。

独立版提供登录页，新保存的数据记录真实操作人。历史记录与商品资料共享，默认配置按登录账号隔离。利润公式继续在前端即时计算，保存时后端再次校验，并将利润输入和结果写入数据库。测算页面只填写商品名称，商品编码、规格编码与商品属性从商品库自动回填并只读展示。店铺在页面物流输入区选择；属性对应的渠道、裸货包装系数、重量档费率与香港店铺规则都在统一配置内维护并保存到数据库。对比临时设置也可调整当次物流配置，不改动统一配置；实际物流成本仍可手动填写。版权费按产品成本计算，其余五项费用按真实营业收入计算。

两处物流配置均分为「商品规则」「渠道运价」「店铺与限制」三个页签：商品规则用表格合并渠道与裸货系数；渠道运价每次显示一个渠道的重量档，选择渠道和计费方式同行；材积除数和最低计费重直接显示在下一行，四个输入框上下等宽对齐。切换页签或渠道保留本次修改，保存统一配置时会包含所有页签的参数。

## 商品基础信息

“统一配置”旁的“商品录入”打开商品资料弹窗，上方录入、下方以表格查看。支持商品名称、规格编码、商品编码和属性组合查询：名称与编码按文本包含匹配、忽略英文大小写，属性精确匹配，各条件取交集；未填写的条件不限制结果，重置显示全部。编码保留前导 0，百分号和下划线按普通字符搜索。支持每页 10/20/50 条、修改和删除已有资料；删除前显示自定义确认弹窗，删除商品资料不影响已保存的历史测算。商品名称去除首尾空白、合并连续空白并忽略英文字母大小写后判重，数据库唯一约束防止并发重复录入。

商品库保存名称、规格编码、商品编码、商品属性、长宽高和实重；两个编码以文本存储并保留前导 0；尺寸类型（包裹/裸货）和店铺在每次测算时现场选择。计算页输入已录入商品的完整名称会自动回填，输入部分名称可选择匹配商品；编码、属性、长宽高和实重均只展示，需修改基础资料时在商品录入弹窗操作。旧商品缺少编码时显示为空，可点击“修改”补齐后使用。更换或清空商品名时清空旧商品的编码、属性和尺寸展示，避免沿用其他商品的数据。历史记录载入仍使用当时保存的快照，商品库更新不改写旧记录。保存测算与商品录入分别操作。

商品编码全库唯一，忽略首尾空格与英文字母大小写，前导 0 保留。数据库唯一索引同时约束新增、修改和并发写入；修改原商品时可保留自己的编码，不能使用其他商品的编码。重复时提示“商品编码已存在，请使用其他编码，或修改已有商品资料。”规格编码不作唯一限制，历史测算中的编码快照也不受商品库唯一限制。旧商品尚未补齐的空编码保留兼容，新录入及修改仍要求填写编码。旧库有重复商品编码时，迁移会报错，应先确认正确编码后修正，不自动删除或重编号。

更换或清空商品名时，同时清空上一件商品的物流成本和利润结果；重新匹配有效商品后再自动估算。物流参数变化后，如果实重或材积对应的计费重超出当前渠道上限、没有匹配运价档位或输入无效，清空旧估算，使用红字说明原因，可人工填写实际物流成本继续测算。未录入商品、缺少编码和表单输入错误也用红字提示；恢复有效输入后解除错误样式。载入历史与初次打开对比时，保留快照中已确认的手动成本。

## 本地启动

要求 Node.js 24+、pnpm 11+ 和 PostgreSQL。数据库名称必须是 `chaoren_profit_dev`；后端会拒绝连接其他库。按 `.env.example` 配置 `.env.local` 中的本机数据库连接。

```sh
pnpm install
pnpm db:migrate
pnpm dev
```

Web 默认地址为 http://127.0.0.1:8081，API 默认监听 127.0.0.1:3002。

验证命令：`pnpm typecheck`、`pnpm test`、`pnpm build`、`pnpm --filter @profit/api smoke`。冒烟测试会创建临时测算记录，并在结束后清理。商品库验证命令：`pnpm --filter @profit/api products:smoke`，覆盖持久化、名称判重、并发写入、查询、分页、修改及删除，结束后只清理其临时商品。

## 数据与版本

独立 `profit` schema 中的 `records` 保存共享测算记录，`products` 保存共享商品资料，`calculation_defaults` 保存每个账号自己的配置。系统初始配置表已移除，初始参数与内部物流规则来自代码。`users`、`sessions` 用于当前登录与权限；旧 `user_settings` 保留兼容。新单新增记录，载入同一单、基于上次数据或接受对比方案后保存追加版本。`record_versions` 保留完整版本历史；历史列表仅显示最新版本，详情和趋势展示全部版本。新保存的版本记录当次真实操作人。

利润输入和计算结果保存在 JSONB 快照中，利润另存数值列供统计。物流长宽高、实重、尺寸类型、店铺及本版本完整物流配置均写入 JSONB 快照，预计运费由后端按快照重新计算并独立保存。历史详情、载入修改、版本回溯和 Excel 导出均使用该版本快照；旧版未保存的物流字段显示为未记录。数据库迁移不再清除物流字段。对比临时设置没有独立配置表，也不修改统一配置；接受新方案时，利润参数和最终采用的物流成本进入历史版本；临时物流渠道配置也进入当前历史版本，载入修改后使用本记录配置，不影响统一配置。当前只支持美国市场，数据模型保留 `market` 字段供未来扩展。Excel 导入及主工作台集成尚未实现。

# 物流计算人工核对数据

核对日期：2026-11-04。基准：外发版 v2026.10.26 HTML 默认物流配置。

## 使用方法

- 长宽高单位为 cm，实重单位为 kg，运费单位为人民币元。
- 本项目统一物流配置必须与 HTML 默认配置一致；生成数据时已确认当前服务的物流配置等于默认值。
- 以下每组数据分别在主页面物流工具和对比方案物流工具核对；对比临时配置应使用默认值。
- 原 HTML 每次改完商品属性、店铺、尺寸类型或输入数值后，都要点击“计算预估运费”。
- 同时核对渠道、计费重、人民币运费；“人工询价”表示不能提供自动报价，此时本项目应禁用填入物流成本。
- 美元展示受汇率影响，本数据以人民币运费为核对标准。

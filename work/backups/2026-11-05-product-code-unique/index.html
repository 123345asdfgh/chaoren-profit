计算公式与使用说明

使用流程

  1. 先录入商品：点击右上角“商品录入”，填写商品名称、规格编码、商品编码、商品属性、长宽高和实重。商品相关信息需先录入才会在测算页显示；同名商品不能重复录入，资料有变动时点击表格中的“修改”。两个编码按文本保存，保留前导 0；已有商品缺少编码时请先补齐。
  2. 选择商品：在测算页输入完整商品名称，编码、属性、长宽高和实重自动显示；输入部分名称可从建议列表选择。未录入的商品请先添加资料，更换或清空名称会清空原商品信息。
  3. 确认物流成本：尺寸类型（包裹 / 裸货）和店铺需要每单现场选择。系统按商品资料及物流配置估算运费，填入“实际物流成本”；可按实际报价修改该金额，利润按最终填写的成本计算，修改成本不会改变商品尺寸。
  4. 填写成交数据：填写中国组合价后，系统按参考售价倍率和结算汇率换算美区商品售价，售价仍可手动修改。买家运费按实际情况填写，利润随输入实时更新。
  5. 确认本单配置：新建测算使用“统一配置”。载入历史后使用记录当时的配置，可在下方“本记录配置”修改；对比时可打开“对比临时设置”，每次打开对比都默认使用统一配置，临时改动仅随接受并保存的方案记入历史，不修改统一配置。
  6. 保存与修改：商品录入只保存商品基础资料；测算完成后还需确认保存，才会生成历史记录。历史中先查看详情，再点击“载入”修改，保存后生成新版本并保留上一版供恢复。载入后点击“重开一单”可清空当前表单，开始新增记录。商品库修改不改变已保存的历史快照。
  7. 查询与导出：商品录入列表可组合使用名称、规格编码、商品编码和属性筛选，点击“查询”生效，“重置”显示全部。历史记录也默认显示全部，筛选后只显示匹配记录；导出 Excel 会导出当前筛选条件下的全部记录，不限于当前页。

未保存的测算输入刷新后清空。页面上方人民币与美元输入框按配置汇率双向换算，用于日常参考。

计算公式

参考美区商品价（💲）＝中国组合价（RMB）×参考售价倍率÷结算汇率 含税实收（💲）＝商品售价＋自行填写的买家运费 真实营业收入（RMB）＝含税实收（💲）×结算汇率÷去税除数 产品成本（RMB）＝中国组合价×产品成本比例 版权费＝产品成本×版权费率 其余五项费用＝真实营业收入×对应费率 税前利润＝真实营业收入－产品成本－六项费用－实际物流成本 所得税＝MAX(税前利润,0)×所得税率 净利润＝税前利润－所得税；净利率＝净利润÷真实营业收入

零营业收入不计算净利率；亏损所得税为 0。结果保留两位小数，计算时不提前舍入。

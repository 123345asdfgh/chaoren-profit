# 跨境日常辅助测算 · 独立全栈版

本项目只在当前目录开发，技术栈参考 chaoren-ai：pnpm workspace、TypeScript、Next.js 16/React 19、Fastify 5、Zod 4、PostgreSQL。主项目源码未改动。

## 页面与功能

- `/calculator`：直接进入原有测算界面，保留品牌区、中美实时钟、利润卡片、即时对比；不显示地球进入页。产品信息独立填写商品属性，中国组合价自动生成可修改的美区商品售价；产品信息下方直接填写物流长宽高、实重、尺寸类型和店铺，按商品属性与渠道自动显示预计运费。裸货先换算包装尺寸与重量。修改物流输入或物流配置后，估算值自动填入实际物流成本；用户可以手动覆盖，修改成本不会反改物流输入，利润始终按实际物流成本输入框计算。载入历史记录只恢复原值，不用估算覆盖已保存成本。对比中的物流输入同样直接显示并支持自动估算与手动覆盖。美国时间卡右下角的小框可按统一配置汇率双向换算金额，美国时间地区在统一配置中选择太平洋、山地、中部或东部。对比临时设置每次打开都从已保存的统一配置开始，接受新方案会按当次临时参数计算并保存为新版本。载入旧记录后可在页面下方修改本记录配置；此时右上角出现“重开一单”，用于清空已载入记录并新建一条独立记录。右上角还可打开统一配置弹窗或进入历史记录。计算页没有存档搜索栏。确认保存成功后弹窗提示当前版本。
- `/history`：默认显示所有人保存的测算记录，筛选后只显示符合条件的记录。可按商品名称、商品编码、规格编码、商品属性多选、操作人和日期搜索，每页可选 10、20、50 条。导出 Excel（.xlsx）使用当前筛选条件，导出全部匹配记录，不受当前页数限制；历史测算工作表每条记录横向占一行，包含物流输入、利润参数、实际成本和预计运费；物流配置工作表保存每条记录的完整商品规则、渠道重量档和店铺规则。单元格居中、带框线，表头与交替行沿用奶油橙配色，冻结表头与识别列。计算页不再提供本单导出。查看详情弹窗可查看物流输入、预计运费、实际成本及该版本的完整配置，再选择载入并修改；也可恢复上一版或删除记录。页面不显示统计区。

独立版不提供登录页。操作人字段保留用于之后接入主项目身份；独立版新记录尚无操作人。当前记录与统一配置对所有使用者共享。利润公式继续在前端即时计算，保存时后端再次校验，并将利润输入和结果写入数据库。保存表单填写商品名称、商品编码、规格编码与商品属性。店铺在页面物流输入区选择；属性对应的渠道、裸货包装系数、重量档费率与香港店铺规则都在统一配置内维护并保存到数据库。对比临时设置也可调整当次物流配置，不改动统一配置；实际物流成本仍可手动填写。版权费按产品成本计算，其余五项费用按真实营业收入计算。

两处物流配置均分为「商品规则」「渠道运价」「店铺与限制」三个页签：商品规则用表格合并渠道与裸货系数；渠道运价每次显示一个渠道的重量档，选择渠道和计费方式同行；材积除数和最低计费重直接显示在下一行，四个输入框上下等宽对齐。切换页签或渠道保留本次修改，保存统一配置时会包含所有页签的参数。

## 本地启动

要求 Node.js 24+、pnpm 11+ 和 PostgreSQL。数据库名称必须是 `chaoren_profit_dev`；后端会拒绝连接其他库。按 `.env.example` 配置 `.env.local` 中的本机数据库连接。

```sh
pnpm install
pnpm db:migrate
pnpm dev
```

Web 默认地址为 http://127.0.0.1:8081，API 默认监听 127.0.0.1:3002。

验证命令：`pnpm typecheck`、`pnpm test`、`pnpm build`、`pnpm --filter @profit/api smoke`。冒烟测试会创建临时测算记录，并在结束后清理。

## 数据与版本

独立 `profit` schema 中的 `records` 保存所有人的记录，`global_settings` 保存共享配置。旧版 `users`、`sessions` 和 `user_settings` 表保留，以兼容现有数据，但当前业务流程不使用它们。新记录不保存订单编号和商品规格；旧记录的这两列原值保留。新单保存时总是新增记录，即使商品编码相同；载入历史记录后再保存，才按记录 ID 修改，并把原快照转为 `previous_snapshot`、新方案作为当前版。恢复上一版时两份快照和版本号一起交换，例如第 3 版恢复后显示第 2 版，且可切回第 3 版。目前只保留一份上一版。

利润输入和计算结果保存在 JSONB 快照中，利润另存数值列供统计。物流长宽高、实重、尺寸类型、店铺及本版本完整物流配置均写入 JSONB 快照，预计运费由后端按快照重新计算并独立保存。历史详情、载入修改、版本回溯和 Excel 导出均使用该版本快照；旧版未保存的物流字段显示为未记录。数据库迁移不再清除物流字段。对比临时设置没有独立配置表，也不修改统一配置；接受新方案时，利润参数和最终采用的物流成本进入历史版本；临时物流渠道配置也进入当前历史版本，载入修改后使用本记录配置，不影响统一配置。当前只支持美国市场，数据模型保留 `market` 字段供未来扩展。Excel 导入及主工作台集成尚未实现。
